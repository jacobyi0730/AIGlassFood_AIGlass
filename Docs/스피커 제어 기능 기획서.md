# AIGlassFood 스피커 제어 기능 기획서

작성일: 2026-08-14  
대상 앱: AIGlassFood  
패키지명: com.mtvs.food  
대상 디바이스: Meta Ray-Ban AI Glasses

## 1. 개요

AIGlassFood 앱에 Meta Ray-Ban AI Glasses의 스피커 출력 테스트 기능을 추가한다. 사용자는 앱 화면에서 문장을 입력하고 `읽기` 버튼을 누른다. 앱은 Android TextToSpeech(TTS) 기능으로 문장을 음성으로 변환해 재생하고, 휴대폰의 현재 미디어 출력 장치가 Meta Ray-Ban으로 설정되어 있으면 안경 스피커에서 소리가 출력된다.

이 기능의 목적은 Ray-Ban Meta의 스피커가 Android 앱의 오디오 출력 장치로 정상 동작하는지 테스트하고, 향후 마이크 및 안경다리 터치 입력 테스트 기능과 함께 AI 글래스 입출력 진단 화면으로 확장하기 위한 기반을 마련하는 것이다.

## 2. 배경

현재 AIGlassFood 앱은 `meta-wearables-dat-android`의 CameraAccess 샘플을 기반으로 생성되어 있으며, Meta Wearables Device Access Toolkit(DAT)을 통해 Ray-Ban Meta와의 등록, 권한, 세션, 카메라 스트리밍 흐름을 다루는 구조를 가진다.

스피커 출력은 DAT의 카메라 권한처럼 별도의 디바이스 capability로 직접 제어하기보다는 Android의 표준 오디오 출력 경로를 이용한다. 즉, Ray-Ban Meta가 휴대폰과 Bluetooth 오디오 장치로 연결되어 있고 미디어 출력 대상으로 선택되어 있으면, 앱에서 재생하는 TTS 음성이 안경 스피커로 출력된다.

## 3. 목표

- 앱에서 사용자가 입력한 텍스트를 Android TTS로 음성 출력한다.
- Meta Ray-Ban이 Bluetooth 오디오 출력 장치로 연결되어 있는지 확인한다.
- Ray-Ban Meta가 연결되어 있지 않거나 현재 출력 장치가 아닌 경우 사용자가 상태를 이해하고 설정으로 이동할 수 있게 안내한다.
- TTS 재생, 일시정지/중지, 재입력, 반복 테스트가 가능한 단순하고 안정적인 스피커 테스트 화면을 제공한다.
- 추후 마이크 입력 테스트와 안경다리 터치 버튼 테스트 화면으로 확장 가능한 구조를 만든다.

## 4. 비목표

- 앱이 Android 시스템 권한을 우회해 Ray-Ban Meta를 강제로 오디오 출력 장치로 전환하지 않는다.
- Ray-Ban Meta 내부 펌웨어의 스피커 볼륨, EQ, 좌우 밸런스 등 하드웨어 레벨 제어는 포함하지 않는다.
- DAT SDK에 존재하지 않는 스피커 전용 API를 가정하지 않는다.
- Meta AI 앱의 페어링 절차를 앱 내부에서 대체하지 않는다.

## 5. 사용자 시나리오

### 5.1 정상 흐름

1. 사용자는 Ray-Ban Meta를 휴대폰에 Bluetooth로 연결한다.
2. Android 미디어 출력 장치가 Ray-Ban Meta로 선택되어 있다.
3. 사용자는 AIGlassFood 앱에서 `스피커 테스트` 화면으로 이동한다.
4. 텍스트 입력창에 “안녕하세요. AIGlassFood 스피커 테스트입니다.”를 입력한다.
5. `읽기` 버튼을 누른다.
6. 앱은 Android TTS로 문장을 합성하고 재생한다.
7. Ray-Ban Meta 스피커에서 음성이 출력된다.
8. 화면에는 `재생 중`, `재생 완료` 상태가 표시된다.

### 5.2 Ray-Ban Meta 미연결 흐름

1. 사용자가 스피커 테스트 화면에 진입한다.
2. 앱이 Bluetooth 출력 장치 목록에서 Ray-Ban Meta로 추정되는 장치를 찾지 못한다.
3. 화면 상단에 `Ray-Ban Meta가 오디오 출력 장치로 연결되어 있지 않습니다.` 안내를 표시한다.
4. 사용자는 `Bluetooth 설정 열기` 버튼을 눌러 시스템 설정으로 이동한다.
5. 연결 후 앱으로 돌아와 다시 테스트한다.

### 5.3 출력 장치 불확실 흐름

1. Ray-Ban Meta는 연결되어 있지만 현재 미디어 출력이 휴대폰 스피커일 수 있다.
2. 앱은 `휴대폰의 미디어 출력이 Ray-Ban Meta인지 확인해주세요.` 안내를 표시한다.
3. 사용자는 Android 시스템의 미디어 출력 선택 UI 또는 Bluetooth 설정에서 출력 장치를 변경한다.
4. 앱에서 `읽기`를 다시 누른다.

## 6. 기능 요구사항

### 6.1 스피커 테스트 화면

- 화면 이름: `Speaker Test`
- 진입 위치: 기존 홈 또는 디버그 메뉴에 `스피커 테스트` 항목 추가
- 구성 요소:
  - Bluetooth 오디오 연결 상태 표시
  - 텍스트 입력창
  - `읽기` 버튼
  - `중지` 버튼
  - 음성 속도 조절 슬라이더
  - 음성 톤 조절 슬라이더
  - 테스트용 기본 문장 버튼
  - Bluetooth 설정 열기 버튼

### 6.2 텍스트 입력

- 사용자는 최대 500자까지 입력할 수 있다.
- 빈 문자열 상태에서 `읽기` 버튼을 누르면 `읽을 문장을 입력해주세요.` 메시지를 표시한다.
- 기본 테스트 문장은 다음과 같이 제공한다.
  - “AIGlassFood 스피커 테스트입니다.”
  - “소리가 안경 스피커에서 들리면 테스트 성공입니다.”
  - “주변 소음이 있는 환경에서도 음성이 명확한지 확인해주세요.”

### 6.3 TTS 재생

- Android `TextToSpeech` API를 사용한다.
- 앱 시작 또는 화면 진입 시 TTS 엔진을 초기화한다.
- 한국어 음성을 우선 사용한다.
- 한국어 음성 사용이 불가능한 경우 시스템 기본 언어로 fallback한다.
- `읽기` 버튼 클릭 시 기존 재생 중인 음성을 중지하고 새 문장을 재생한다.
- `중지` 버튼 클릭 시 즉시 재생을 중지한다.
- 재생 완료 콜백을 받아 화면 상태를 `완료`로 갱신한다.

### 6.4 오디오 출력 장치 확인

- Android `AudioManager.getDevices(AudioManager.GET_DEVICES_OUTPUTS)`로 출력 장치 목록을 확인한다.
- Bluetooth 계열 출력 장치를 탐지한다.
  - `TYPE_BLUETOOTH_A2DP`
  - `TYPE_BLUETOOTH_SCO`
  - `TYPE_BLE_HEADSET`
  - `TYPE_BLE_SPEAKER`
- 장치명에 `Ray-Ban`, `Meta`, `Glasses` 등이 포함되면 Ray-Ban Meta 후보로 표시한다.
- 단, Android 앱은 일반적으로 사용자의 미디어 출력 경로를 강제로 바꿀 수 없으므로, 앱은 연결 상태와 안내를 제공하고 최종 출력 선택은 시스템 UI에 맡긴다.

### 6.5 상태 표시

- `준비됨`: TTS 초기화 완료, 입력 가능
- `Ray-Ban 연결 감지`: Bluetooth 출력 장치 목록에 Ray-Ban Meta 후보 있음
- `출력 확인 필요`: Bluetooth 장치는 있으나 현재 미디어 출력 여부가 불확실함
- `재생 중`: TTS 재생 중
- `완료`: TTS 재생 완료
- `오류`: TTS 초기화 실패, 언어 미지원, 입력값 없음, 오디오 장치 미연결 등

## 7. 권한 및 설정

### 7.1 Android 권한

기존 AIGlassFood 앱에 이미 포함된 권한을 활용한다.

- `android.permission.BLUETOOTH`
- `android.permission.BLUETOOTH_CONNECT`
- `android.permission.INTERNET`
- `android.permission.MODIFY_AUDIO_SETTINGS`

Android 12 이상에서는 Bluetooth 장치 이름과 연결 상태 확인을 위해 `BLUETOOTH_CONNECT` 런타임 권한이 필요하다.

### 7.2 시스템 설정 이동

앱에서 직접 출력 장치를 강제 전환하는 대신 다음 설정 화면으로 이동할 수 있는 버튼을 제공한다.

- Bluetooth 설정: `Settings.ACTION_BLUETOOTH_SETTINGS`
- 사운드 설정: `Settings.ACTION_SOUND_SETTINGS`

## 8. 화면 설계

### 8.1 레이아웃

- 상단: 화면 제목 `스피커 테스트`
- 상태 영역: 연결된 Bluetooth 오디오 장치명과 현재 안내 문구
- 입력 영역: 여러 줄 텍스트 입력창
- 제어 영역:
  - `읽기`
  - `중지`
  - `기본 문장`
  - `Bluetooth 설정`
- 옵션 영역:
  - 속도: 0.5x ~ 2.0x
  - 톤: 0.5x ~ 2.0x

### 8.2 UX 원칙

- 테스트 화면은 현장 검증용이므로 한 손으로 빠르게 조작할 수 있어야 한다.
- 연결 문제는 기술 용어보다 사용자가 조치할 수 있는 문장으로 안내한다.
- `Ray-Ban Meta가 연결되어 있지 않습니다.`보다 `Bluetooth에서 Ray-Ban Meta를 연결한 뒤 다시 시도해주세요.`처럼 행동 중심 문구를 사용한다.
- 재생 중에는 `읽기` 버튼을 비활성화하거나 `다시 읽기`로 의미를 명확히 한다.

## 9. 기술 설계

### 9.1 주요 컴포넌트

- `SpeakerTestScreen`
  - Compose UI 화면
  - 텍스트 입력, 버튼, 상태 표시 담당
- `SpeakerTestViewModel`
  - 입력 텍스트, TTS 상태, 오디오 장치 상태 관리
  - TTS 서비스와 오디오 라우팅 검사 호출
- `TtsSpeakerController`
  - `TextToSpeech` 초기화, speak, stop, shutdown 담당
  - utterance progress listener로 재생 상태 전달
- `AudioOutputDeviceMonitor`
  - `AudioManager` 기반 출력 장치 목록 조회
  - Bluetooth/Ray-Ban 후보 장치 탐지

### 9.2 TTS 처리 흐름

1. 화면 진입 시 `TtsSpeakerController.initialize()` 호출
2. TTS 초기화 성공 시 `Ready` 상태 전환
3. 사용자가 텍스트 입력 후 `읽기` 클릭
4. ViewModel이 입력값 검증
5. AudioOutputDeviceMonitor가 Bluetooth 출력 장치 상태 확인
6. TtsSpeakerController가 `TextToSpeech.speak()` 호출
7. 재생 시작/완료/오류 콜백을 ViewModel로 전달
8. 화면 상태 갱신

### 9.3 오디오 속성

TTS 재생 시 미디어 출력 경로를 따르도록 AudioAttributes를 설정한다.

```kotlin
val attributes = AudioAttributes.Builder()
    .setUsage(AudioAttributes.USAGE_MEDIA)
    .setContentType(AudioAttributes.CONTENT_TYPE_SPEECH)
    .build()

textToSpeech.setAudioAttributes(attributes)
```

### 9.4 TTS 재생 예시

```kotlin
textToSpeech.setSpeechRate(speechRate)
textToSpeech.setPitch(pitch)
textToSpeech.speak(
    text,
    TextToSpeech.QUEUE_FLUSH,
    bundleOf(TextToSpeech.Engine.KEY_PARAM_UTTERANCE_ID to utteranceId),
    utteranceId,
)
```

## 10. 예외 처리

### 10.1 TTS 초기화 실패

- 메시지: `TTS 엔진을 초기화할 수 없습니다. Android TTS 설정을 확인해주세요.`
- 조치: Android TTS 설정 화면으로 이동 가능한 버튼 제공 검토

### 10.2 한국어 음성 미지원

- 메시지: `한국어 음성을 사용할 수 없어 기본 음성으로 재생합니다.`
- 조치: 시스템 기본 Locale로 재생

### 10.3 Bluetooth 권한 없음

- 메시지: `Bluetooth 장치 확인 권한이 필요합니다.`
- 조치: `BLUETOOTH_CONNECT` 권한 요청

### 10.4 Ray-Ban Meta 미연결

- 메시지: `Ray-Ban Meta를 Bluetooth 오디오 장치로 연결한 뒤 다시 시도해주세요.`
- 조치: Bluetooth 설정 열기

### 10.5 출력 장치가 휴대폰 스피커인 경우

- 메시지: `소리가 휴대폰에서 들리면 Android 미디어 출력에서 Ray-Ban Meta를 선택해주세요.`
- 조치: 사운드 설정 또는 Bluetooth 설정 열기

## 11. 테스트 계획

### 11.1 단위 테스트

- 빈 문자열 입력 시 재생이 호출되지 않는지 확인
- TTS 초기화 실패 시 오류 상태가 표시되는지 확인
- 속도/톤 값이 허용 범위 안에서만 설정되는지 확인
- Bluetooth 출력 장치 목록 파싱 로직 검증

### 11.2 수동 테스트

- Ray-Ban Meta 연결 전 `읽기` 클릭 시 안내 메시지 확인
- Ray-Ban Meta 연결 후 기본 문장 재생 확인
- 휴대폰 스피커 출력 상태에서 안내 메시지 확인
- Ray-Ban Meta 출력 상태에서 안경 스피커 재생 확인
- 긴 문장 입력 시 끊김 없이 재생되는지 확인
- 재생 중 `중지` 클릭 시 즉시 멈추는지 확인
- 앱 백그라운드 전환 후 복귀 시 TTS 상태가 안정적으로 정리되는지 확인

### 11.3 실제 디바이스 테스트 기준

- 테스트 휴대폰: Android 12 이상
- 테스트 안경: Ray-Ban Meta
- 사전 조건:
  - Meta AI 앱 설치
  - Ray-Ban Meta Bluetooth 페어링 완료
  - AIGlassFood 앱 Bluetooth 권한 허용
  - Android 미디어 출력 장치가 Ray-Ban Meta로 선택됨

## 12. 성공 기준

- 사용자가 입력한 문장이 2초 이내에 TTS 재생을 시작한다.
- Ray-Ban Meta가 미디어 출력 장치로 선택된 상태에서 안경 스피커로 음성이 출력된다.
- 미연결 또는 출력 장치 불확실 상태에서 사용자가 다음 조치를 이해할 수 있는 안내를 받는다.
- 재생 중 중지 기능이 즉시 동작한다.
- 반복 테스트 시 앱이 크래시 없이 안정적으로 동작한다.

| 출력 장치 강제 전환 제한 | 일반 Android 앱은 미디어 출력을 특정 Bluetooth 장치로 강제 전환하기 어렵다. | 연결 상태 확인과 설정 이동 UX를 제공한다. |
| 장치명 탐지 불확실 | Ray-Ban Meta의 Bluetooth 장치명이 사용자 설정에 따라 달라질 수 있다. | Bluetooth 오디오 장치 전체를 보여주고 사용자가 확인할 수 있게 한다. |
| TTS 엔진 차이 | 제조사/사용자 설정에 따라 TTS 품질과 언어 지원이 다르다. | 한국어 우선, 기본 Locale fallback, 오류 안내를 구현한다. |
| 볼륨 문제 | 휴대폰 미디어 볼륨 또는 안경 볼륨이 낮으면 출력 확인이 어렵다. | 테스트 전 미디어 볼륨 확인 안내를 표시한다. |
| 연결 지연 | Bluetooth 연결 직후 오디오 라우팅 반영이 늦을 수 있다. | 새로고침 버튼 또는 화면 재진입 없이 상태 갱신 기능을 제공한다. |

## 15. 향후 확장

- 식사 가이드 문장을 TTS로 Ray-Ban Meta에 안내하는 기능
- 음식 인식 결과를 음성으로 요약해 읽어주는 기능
- 조리 단계별 음성 안내
- 안경다리 터치 입력으로 `다시 읽기`, `다음 안내`, `중지` 제어
- 마이크 음성 명령으로 TTS 문장 선택 또는 음식 기록 제어
