# Ray-Ban Meta 기기 제어 레퍼런스

작성일: 2026-08-18  
기준 프로젝트: `AIGlassFood`  
대상 기능: 카메라, 스피커, 마이크  
대상 디바이스: Meta Ray-Ban AI Glasses

## 1. 핵심 요약

Ray-Ban Meta 기기 제어는 기능별로 접근 방식이 다르다.

| 기능 | 구현 방식 | 핵심 API |
|---|---|---|
| 카메라 | Meta Wearables DAT SDK 세션 + 카메라 스트림 | `Wearables.createSession`, `Permission.CAMERA`, `addCamera` |
| 스피커 | Android TTS를 미디어 출력으로 재생 | `TextToSpeech`, `AudioManager.GET_DEVICES_OUTPUTS` |
| 마이크 | Ray-Ban Bluetooth 입력 감지 후 Android STT 실행 | `AudioManager.GET_DEVICES_INPUTS`, `setCommunicationDevice`, `SpeechRecognizer` |

중요한 원칙:

- 카메라는 DAT SDK capability로 제어한다.
- 스피커와 마이크는 Ray-Ban 전용 공개 API를 가정하지 않고 Android 표준 오디오 라우팅을 사용한다.
- 마이크는 휴대폰 내장 마이크 fallback을 허용하지 않는다. Ray-Ban Meta 후보 입력 장치가 감지된 경우에만 STT를 시작한다.
- 하나의 `MainActivity`에서 Compose 상태만 바꿔 `카메라 / 스피커 / 마이크` 테스트 화면을 전환한다.

## 6. 카메라 제어

### 6.1 동작 흐름

1. `Wearables.initialize(context)` 호출
2. Meta AI 앱을 통해 앱 등록
3. `Wearables.createSession(deviceSelector)`로 세션 생성
4. `session.start()` 호출
5. `Wearables.checkPermissionStatus(Permission.CAMERA)` 확인
6. 권한이 없으면 `Wearables.RequestPermissionContract()`로 Meta AI 앱 권한 요청
7. `session.addCamera(StreamConfiguration(...))`
8. `camera.stream.start()`
9. `stream.videoStream.collect { frame -> ... }`
10. 필요 시 `stream.capturePhoto()`, 녹화, `camera.stop()`, `session.stop()`

### 6.2 세션 시작 예제

```kotlin
private var session: DeviceSession? = null

fun startSession(deviceSelector: DeviceSelector) {
    Wearables.createSession(deviceSelector)
        .onSuccess { created ->
            session = created
            viewModelScope.launch {
                created.state.collect { state ->
                    // DeviceSessionState.STARTING / ACTIVE / STOPPING / STOPPED
                }
            }
            created.start()
        }
        .onFailure { error, _ ->
            Log.e("Camera", "Failed to create session: ${error.description}")
        }
}
```

### 6.3 카메라 스트림 시작 예제

```kotlin
private var camera: Camera? = null
private var stream: Stream? = null

fun startCameraStream() {
    val currentSession = session ?: return

    currentSession.addCamera(
        StreamConfiguration(
            videoQuality = VideoQuality.MEDIUM,
            frameRate = 24,
            compressVideo = true,
        )
    ).onSuccess { addedCamera ->
        camera = addedCamera
        stream = addedCamera.stream

        viewModelScope.launch {
            addedCamera.stream.videoStream.collect { frame ->
                if (!frame.isCompressed) return@collect
                val buffer = frame.buffer
                val bytes = ByteArray(buffer.remaining())
                val position = buffer.position()
                buffer.get(bytes)
                buffer.position(position)

                // bytes: HEVC compressed frame
                // decoder 또는 recorder에 전달
            }
        }

        addedCamera.stream.start()
    }
}
```

### 6.4 사진 캡처 예제

```kotlin
fun capturePhoto() {
    viewModelScope.launch {
        stream?.capturePhoto()
            ?.onSuccess { photoData ->
                when (photoData) {
                    is PhotoData.Bitmap -> {
                        val bitmap = photoData.bitmap
                    }
                    is PhotoData.HEIC -> {
                        val bytes = ByteArray(photoData.data.remaining())
                        photoData.data.get(bytes)
                    }
                }
            }
            ?.onFailure { error, _ ->
                Log.e("Camera", "Capture failed: ${error.description}")
            }
    }
}
```

## 7. 스피커 제어

Ray-Ban Meta 스피커는 앱이 직접 하드웨어 API로 제어하지 않는다. Android 미디어 출력 대상이 Ray-Ban Meta로 선택되어 있으면 `TextToSpeech` 출력이 안경 스피커에서 재생된다.

### 7.1 출력 장치 탐지

```kotlin
fun scanBluetoothOutputs(context: Context): List<AudioDeviceInfo> {
    val audioManager = context.getSystemService(AudioManager::class.java)
    return audioManager.getDevices(AudioManager.GET_DEVICES_OUTPUTS)
        .filter { device ->
            device.type == AudioDeviceInfo.TYPE_BLUETOOTH_A2DP ||
                device.type == AudioDeviceInfo.TYPE_BLUETOOTH_SCO ||
                device.type == AudioDeviceInfo.TYPE_BLE_HEADSET ||
                device.type == AudioDeviceInfo.TYPE_BLE_SPEAKER
        }
}

fun isRayBanCandidate(name: String): Boolean {
    val normalized = name.lowercase()
    return normalized.contains("ray-ban") ||
        normalized.contains("rayban") ||
        normalized.contains("meta") ||
        normalized.contains("glasses")
}
```

### 7.2 TTS 재생 예제

```kotlin
class TtsSpeakerController(
    context: Context,
    private val onDone: () -> Unit,
) : TextToSpeech.OnInitListener {

    private var tts: TextToSpeech? = TextToSpeech(context.applicationContext, this)

    override fun onInit(status: Int) {
        val engine = tts ?: return
        if (status != TextToSpeech.SUCCESS) return

        engine.setLanguage(Locale.KOREAN)
        engine.setAudioAttributes(
            AudioAttributes.Builder()
                .setUsage(AudioAttributes.USAGE_MEDIA)
                .setContentType(AudioAttributes.CONTENT_TYPE_SPEECH)
                .build()
        )
        engine.setOnUtteranceProgressListener(object : UtteranceProgressListener() {
            override fun onStart(utteranceId: String?) = Unit
            override fun onDone(utteranceId: String?) = onDone()
            override fun onError(utteranceId: String?) = Unit
        })
    }

    fun speak(text: String) {
        val utteranceId = "tts-${System.currentTimeMillis()}"
        val params = Bundle().apply {
            putString(TextToSpeech.Engine.KEY_PARAM_UTTERANCE_ID, utteranceId)
        }
        tts?.speak(text, TextToSpeech.QUEUE_FLUSH, params, utteranceId)
    }

    fun shutdown() {
        tts?.stop()
        tts?.shutdown()
        tts = null
    }
}
```

## 8. 마이크 제어

요구사항이 “휴대폰 마이크 제외, Ray-Ban Meta 마이크 사용”이면 STT 시작 전에 반드시 Bluetooth 입력 장치를 확인해야 한다. Ray-Ban 후보 장치가 없으면 `SpeechRecognizer`를 시작하지 않는다.

### 8.1 입력 장치 탐지

```kotlin
fun scanRayBanInputs(context: Context): List<AudioDeviceInfo> {
    val audioManager = context.getSystemService(AudioManager::class.java)
    return audioManager.getDevices(AudioManager.GET_DEVICES_INPUTS)
        .filter { device ->
            device.type == AudioDeviceInfo.TYPE_BLUETOOTH_SCO ||
                device.type == AudioDeviceInfo.TYPE_BLE_HEADSET
        }
        .filter { device ->
            val name = device.productName?.toString().orEmpty().lowercase()
            name.contains("ray-ban") ||
                name.contains("rayban") ||
                name.contains("meta") ||
                name.contains("glasses")
        }
}
```

### 8.2 Ray-Ban 입력 라우팅 요청

```kotlin
fun requestRayBanMicRoute(context: Context): Boolean {
    val audioManager = context.getSystemService(AudioManager::class.java)
    val rayBanDevice = audioManager.availableCommunicationDevices.firstOrNull { device ->
        val name = device.productName?.toString().orEmpty().lowercase()
        val isBluetooth =
            device.type == AudioDeviceInfo.TYPE_BLUETOOTH_SCO ||
                device.type == AudioDeviceInfo.TYPE_BLE_HEADSET
        isBluetooth &&
            (name.contains("ray-ban") ||
                name.contains("rayban") ||
                name.contains("meta") ||
                name.contains("glasses"))
    } ?: return false

    audioManager.mode = AudioManager.MODE_IN_COMMUNICATION
    return audioManager.setCommunicationDevice(rayBanDevice)
}

fun releaseMicRoute(context: Context) {
    val audioManager = context.getSystemService(AudioManager::class.java)
    audioManager.clearCommunicationDevice()
    audioManager.mode = AudioManager.MODE_NORMAL
}
```

### 8.3 STT 예제

```kotlin
class SpeechToTextController(
    private val context: Context,
    private val onPartial: (String) -> Unit,
    private val onFinal: (List<String>) -> Unit,
    private val onError: (Int) -> Unit,
) {
    private var recognizer: SpeechRecognizer? = null

    fun start() {
        if (!SpeechRecognizer.isRecognitionAvailable(context)) return

        recognizer = SpeechRecognizer.createSpeechRecognizer(context).also { speech ->
            speech.setRecognitionListener(object : RecognitionListener {
                override fun onReadyForSpeech(params: Bundle?) = Unit
                override fun onBeginningOfSpeech() = Unit
                override fun onRmsChanged(rmsdB: Float) = Unit
                override fun onBufferReceived(buffer: ByteArray?) = Unit
                override fun onEndOfSpeech() = Unit
                override fun onError(error: Int) = onError(error)
                override fun onEvent(eventType: Int, params: Bundle?) = Unit

                override fun onPartialResults(partialResults: Bundle?) {
                    val text = partialResults
                        ?.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION)
                        ?.firstOrNull()
                        .orEmpty()
                    if (text.isNotBlank()) onPartial(text)
                }

                override fun onResults(results: Bundle?) {
                    val values = results
                        ?.getStringArrayList(SpeechRecognizer.RESULTS_RECOGNITION)
                        .orEmpty()
                    onFinal(values)
                }
            })
        }

        val intent = Intent(RecognizerIntent.ACTION_RECOGNIZE_SPEECH).apply {
            putExtra(RecognizerIntent.EXTRA_LANGUAGE_MODEL, RecognizerIntent.LANGUAGE_MODEL_FREE_FORM)
            putExtra(RecognizerIntent.EXTRA_LANGUAGE, "ko-KR")
            putExtra(RecognizerIntent.EXTRA_PARTIAL_RESULTS, true)
            putExtra(RecognizerIntent.EXTRA_MAX_RESULTS, 3)
        }
        recognizer?.startListening(intent)
    }

    fun stop() {
        recognizer?.stopListening()
    }

    fun destroy() {
        recognizer?.destroy()
        recognizer = null
    }
}
```

### 8.4 마이크 시작 순서

```kotlin
fun startRayBanStt(context: Context, stt: SpeechToTextController) {
    val rayBanInputs = scanRayBanInputs(context)
    if (rayBanInputs.isEmpty()) {
        // 휴대폰 마이크 fallback 금지
        return
    }

    val routed = requestRayBanMicRoute(context)
    if (!routed) {
        return
    }

    stt.start()
}
```

## 10. 구현 시 주의사항

- `SpeechRecognizer`는 입력 장치를 직접 지정하는 API가 아니다. Ray-Ban 마이크만 허용하려면 STT 시작 전에 Bluetooth 입력 장치와 통신 라우팅을 확인해야 한다.
- Android 오디오 라우팅은 기기와 OS 버전에 따라 달라질 수 있다. 실제 검증은 Ray-Ban을 착용하고 휴대폰을 멀리 둔 상태에서 진행한다.
- TTS 출력 장치는 앱이 강제로 Ray-Ban으로 전환하지 않는다. 사용자가 Android 미디어 출력에서 Ray-Ban Meta를 선택해야 한다.
- DAT 카메라 권한은 일반 Android `CAMERA` 권한과 별개로 Meta AI 앱을 통한 `Permission.CAMERA` 승인이 필요하다.
- 카메라 스트림과 녹화는 앱 백그라운드 전환을 고려해 foreground service와 wake lock을 검토한다.
- `TextToSpeech.shutdown()`, `SpeechRecognizer.destroy()`, `AudioManager.clearCommunicationDevice()`는 화면 종료 시 반드시 호출한다.
