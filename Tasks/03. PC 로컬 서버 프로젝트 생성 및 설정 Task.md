## 목적

Android 앱의 요청을 수신하고 NVIDIA API Key를 안전하게 관리하는 Node.js 기반 PC 로컬 서버를 구성한다.

## 작업 항목

- [ ] 저장소 루트에 Android 프로젝트와 분리된 `FoodServer` 프로젝트를 생성한다.
- [ ] Node.js, Express, multipart 업로드 라이브러리와 환경 변수 로더를 설정한다.
- [ ] 개발/실행/테스트 스크립트를 `package.json`에 정의한다.
- [ ] `.env.example`에 `NVIDIA_API_KEY`, `NVIDIA_BASE_URL`, `NVIDIA_MODEL`, `SERVER_PORT`를 문서화한다.
- [ ] 실제 `.env`, API Key, 업로드 임시 파일이 Git에 포함되지 않도록 `.gitignore`를 구성한다.
- [ ] 서버를 `0.0.0.0`과 설정된 포트에서 실행해 같은 Wi-Fi의 Android 기기가 접근할 수 있게 한다.
- [ ] `GET /health` 상태 확인 API를 추가한다.
- [ ] `POST /api/recipe`에 메모리 기반 `multipart/form-data` 수신을 구현한다.
- [ ] 요청의 `image`, `prompt`, 선택 `language` 필드를 검증한다.
- [ ] 업로드 크기를 8MB로 제한하고 이미지 MIME 형식을 검증한다.
- [ ] 공통 오류 응답 형식과 요청 식별자를 정의하되 이미지 원본, 전체 프롬프트, API Key를 로그에 남기지 않는다.
- [ ] 종료 신호 처리와 예상치 못한 오류 처리기를 추가한다.
- [ ] 로컬 실행 방법, 방화벽/동일 Wi-Fi 확인 방법, 환경 변수 설정 방법을 README에 작성한다.
- [ ] 정상 요청 및 필수 값 누락, 잘못된 형식, 8MB 초과 요청에 대한 서버 테스트를 추가한다.

## 서버 API 계약

```http
POST /api/recipe
Content-Type: multipart/form-data

image: <image file>       # 필수
prompt: <string>          # 필수, 공백 제외
language: ko-KR           # 선택, 기본값 ko-KR
```

성공 응답:

```json
{
  "recipeText": "string",
  "model": "string",
  "elapsedMs": 0
}
```

오류 응답:

```json
{
  "message": "string",
  "code": "string"
}
```

## 완료 조건

- [ ] 환경 변수만 설정하면 PC에서 서버를 실행할 수 있다.
- [ ] Android 기기와 같은 Wi-Fi에서 `/health`와 `/api/recipe`에 접근할 수 있다.
- [ ] 잘못된 요청이 NVIDIA API로 전달되지 않고 일관된 4xx 오류를 반환한다.

## 개발 메모

- MVP 요청 이미지는 디스크에 저장하지 않고 메모리에서 처리한다.
- 로컬 개발에서는 서버가 외부 인터페이스를 수신하므로 방화벽 허용 범위를 개발 PC와 신뢰할 수 있는 네트워크로 제한한다.
