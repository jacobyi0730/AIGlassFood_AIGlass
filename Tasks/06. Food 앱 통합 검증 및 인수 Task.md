# 06. Food 앱 통합 검증 및 인수 Task

작성일: 2026-08-19  
대상 프로젝트: `AIGlassFood`, `FoodServer`  
기획서: `Docs/Food기획.md`  
선행 Task: `01`~`05` Task 완료

## 목적

Android 앱, PC 로컬 서버, NVIDIA Nemotron API와 실제 Meta Ray-Ban을 연결해 전체 사용자 흐름과 오류 처리를 검증하고 개발 결과를 인수 가능한 상태로 만든다.

## 작업 항목

- [ ] Android 앱 debug 빌드와 단위/UI 테스트를 통과시킨다.
- [ ] PC 서버 테스트와 lint가 구성된 경우 lint를 통과시킨다.
- [ ] Ray-Ban 등록/미등록, 카메라 세션 성공/실패 상태를 실제 기기에서 확인한다.
- [ ] 음식과 식재료 이미지를 각각 촬영하고 미리보기를 확인한다.
- [ ] Ray-Ban 마이크 STT가 동작하고 휴대폰 내장 마이크 fallback이 차단되는지 확인한다.
- [ ] STT 결과를 직접 수정한 내용이 서버 요청에 반영되는지 확인한다.
- [ ] 요청 중 중복 전송 방지와 긴 응답 대기 UI를 확인한다.
- [ ] 정상 레시피 결과와 서버 미실행, 잘못된 주소, NVIDIA 오류 상태를 확인한다.
- [ ] Ray-Ban이 Android 미디어 출력 장치로 선택된 상태에서 레시피 TTS를 확인한다.
- [ ] 긴 레시피에서 전체 화면 세로 스크롤과 TTS 중지를 확인한다.
- [ ] 앱 및 서버 README에 빌드, 설정, 실행, 테스트, 실제 기기 연결 순서를 갱신한다.
- [ ] 실사용 로그에 이미지 원본, 전체 프롬프트, NVIDIA API Key가 남지 않는지 점검한다.

## 최종 인수 기준

- [ ] 사용자가 하나의 세로 스크롤 화면에서 촬영, 음성 프롬프트 작성/수정, 레시피 조회, 결과 확인, TTS 재생을 완료할 수 있다.
- [ ] 이미지와 프롬프트가 PC 서버를 거쳐 NVIDIA Nemotron API에 전달되고 레시피 결과가 앱으로 반환된다.
- [ ] NVIDIA API Key가 서버 밖으로 노출되지 않는다.
- [ ] Ray-Ban 마이크 미감지 시 휴대폰 마이크로 자동 대체되지 않는다.
- [ ] 서버 연결과 외부 API 실패 시 사용자가 다음 조치를 알 수 있는 메시지가 표시된다.
- [ ] Android와 서버의 자동화 테스트 및 실제 Ray-Ban 통합 시나리오가 통과한다.

## 인수 제외 범위

- 사용자 계정 및 인증
- 식사 기록 저장과 즐겨찾기
- 칼로리 및 영양 정보의 의학적 정확성 보장
- 알레르기 판정 또는 의료 조언
- Meta AI 앱이나 안경 펌웨어 기능 대체
- 다국어 응답, 구조화 레시피 카드, 단계별 TTS 등 기획서의 2·3단계 기능
