## 목표

기존 `AIGlassFood` 프로젝트를 음식 레시피 추천 앱으로 리뉴얼한다. 사용자는 하나의 세로 스크롤 화면에서 Meta Ray-Ban 카메라로 음식 이미지를 촬영하고, 안경 마이크의 STT 결과를 프롬프트로 확인·수정한 뒤 PC 로컬 서버에 레시피를 요청한다. 서버는 NVIDIA Nemotron API를 호출하며, 앱은 받은 레시피를 표시하고 Meta Ray-Ban 스피커를 통해 TTS로 재생한다.

## 공통 원칙

- 기존 Meta Wearables DAT 카메라 세션, 마이크/STT, 스피커/TTS 구현은 재사용하되 Food 흐름에 맞게 리팩터링한다.
- Food의 핵심 흐름은 화면 전환 없이 하나의 `FoodRecipeScreen`에서 처리한다.
- 전체 화면은 `LazyColumn` 또는 세로 스크롤이 가능한 동등한 Compose 구조로 구현한다.
- Ray-Ban Meta 입력 장치가 감지되지 않으면 휴대폰 내장 마이크로 자동 대체하지 않는다.
- TTS 출력 장치를 앱에서 강제로 변경하지 않고 현재 Android 미디어 출력 장치와 설정 이동 안내를 제공한다.
- NVIDIA API Key는 PC 서버 환경 변수에만 저장하며 Android 앱, 소스 코드, 로그에 포함하지 않는다.
- 이미지와 프롬프트는 사용자가 `레시피 조회`를 실행한 경우에만 서버로 전송한다.
- MVP에서는 요청 이미지를 서버 디스크에 영구 저장하지 않고 메모리에서 처리한다.

## 전체 제외 범위

- 사용자 계정 및 인증
- 식사 기록 저장과 즐겨찾기
- 칼로리 및 영양 정보의 의학적 정확성 보장
- 알레르기 판정 또는 의료 조언
- Meta AI 앱이나 안경 펌웨어 기능 대체
- 다국어 응답, 구조화 레시피 카드, 단계별 TTS 등 기획서의 2·3단계 기능
