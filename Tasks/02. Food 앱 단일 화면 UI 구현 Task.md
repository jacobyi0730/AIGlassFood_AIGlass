# 02. Food 앱 단일 화면 UI 구현 Task

작성일: 2026-08-19  
대상 프로젝트: `AIGlassFood`  
기획서: `Docs/Food기획.md`  
선행 Task: `01. Food 앱 기능 구현 Task`

## 목적

Food의 모든 핵심 기능을 화면 이동 없이 사용할 수 있는 하나의 세로 스크롤 Compose 화면으로 구현한다.

## 작업 항목

- [ ] 기존 홈/기능별 테스트 화면 중심의 진입 흐름을 `FoodRecipeScreen` 중심으로 리뉴얼한다.
- [ ] 화면 전체를 `LazyColumn` 또는 `verticalScroll`로 구성해 작은 화면에서도 모든 영역에 접근할 수 있게 한다.
- [ ] 상단에 Ray-Ban 등록, 연결, 카메라 세션, 마이크 및 스피커 상태를 간결하게 표시한다.
- [ ] 카메라 미리보기 또는 촬영 이미지 영역을 구현한다.
- [ ] `촬영`과 `다시 촬영` 버튼을 이미지 상태에 맞게 노출한다.
- [ ] `음성 시작`/`음성 종료` 버튼과 현재 청취 상태를 표시한다.
- [ ] STT 결과가 반영되는 편집 가능한 프롬프트 입력 영역과 `초기화` 버튼을 구현한다.
- [ ] `레시피 조회` 버튼을 구현하고 요청 중에는 중복 클릭을 차단하며 로딩 상태를 표시한다.
- [ ] 레시피 결과를 읽기 쉬운 텍스트 영역에 표시한다.
- [ ] `레시피 TTS`와 `TTS 중지` 버튼을 재생 상태에 따라 제공한다.
- [ ] Ray-Ban 미등록, 이미지 없음, 프롬프트 없음, 마이크/스피커 미감지, 서버 연결 실패, NVIDIA 오류를 화면 내 메시지로 표시한다.
- [ ] Bluetooth 또는 앱 설정으로 이동해야 하는 오류에는 실행 가능한 안내 버튼을 제공한다.
- [ ] 긴 프롬프트와 긴 레시피에서도 버튼이 가려지지 않고 세로 스크롤되는지 확인한다.
- [ ] 콘텐츠 설명, 터치 영역, 색상 대비와 로딩 상태 등 기본 접근성을 적용한다.
- [ ] 사용자 노출 문구를 `strings.xml` 리소스로 분리한다.
- [ ] 주요 상태별 Compose UI 테스트를 추가한다.

## 화면 순서

```text
[Ray-Ban 및 장치 상태]
[카메라 미리보기 또는 촬영 이미지]
[촬영] [다시 촬영]
[음성 시작/종료]
[프롬프트 입력 및 수정]
[초기화]
[레시피 조회 + 요청 상태]
[레시피 결과]
[레시피 TTS] [TTS 중지]
```

## 완료 조건

- [ ] 한 화면에서 촬영, 음성 입력, 프롬프트 수정, 조회, 결과 확인, TTS 재생을 완료할 수 있다.
- [ ] 콘텐츠 길이와 기기 화면 크기에 관계없이 세로 스크롤로 모든 컨트롤에 접근할 수 있다.
- [ ] 요청 중, 오류, 빈 상태, 성공 상태가 서로 구분되어 표시된다.

## 개발 메모

- 기능별 테스트 화면을 곧바로 제거하지 말고 Food 화면이 검증될 때까지 회귀 테스트 용도로 유지할 수 있다.
- 화면은 `FoodRecipeUiState`와 이벤트 콜백을 입력받는 상태 비소유 Composable로 분리해 UI 테스트가 가능하게 한다.
