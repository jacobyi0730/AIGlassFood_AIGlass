# 04. 서버와 NVIDIA Nemotron 통신 구현 Task

작성일: 2026-08-19  
대상 프로젝트: `FoodServer`  
기획서: `Docs/Food기획.md`  
선행 Task: `03. PC 로컬 서버 프로젝트 생성 및 설정 Task`

## 목적

서버가 음식 이미지와 사용자 프롬프트를 NVIDIA의 이미지 입력 지원 Nemotron 계열 모델에 전달하고 안전한 한국어 레시피 텍스트를 반환하게 한다.

## 작업 항목

- [ ] NVIDIA API Catalog에서 실제 사용 가능한 이미지 입력 지원 Nemotron 계열 모델과 요청 형식을 확인한다.
- [ ] 모델명과 base URL을 환경 변수로 교체할 수 있게 구현하고 코드에 특정 모델을 고정하지 않는다.
- [ ] OpenAI 호환 클라이언트 또는 NVIDIA가 제공하는 공식 요청 방식으로 API 클라이언트를 구성한다.
- [ ] 업로드 이미지의 MIME 형식과 Base64 데이터를 멀티모달 요청 형식으로 변환한다.
- [ ] 기획서의 시스템 프롬프트와 사용자 프롬프트 템플릿을 별도 모듈로 분리한다.
- [ ] 결과에 요리명, 확인/추정 재료, 추가 재료, 예상 시간, 단계별 조리법, 팁, 주의사항이 포함되도록 프롬프트를 구성한다.
- [ ] 식재료가 확실하지 않으면 추정임을 밝히고 위험한 조리법이나 단정적인 알레르기 판단을 하지 않도록 안전 지침을 포함한다.
- [ ] API 응답에서 비어 있지 않은 텍스트를 추출하고 `recipeText`, `model`, `elapsedMs`로 정규화한다.
- [ ] 인증 실패, rate limit, timeout, 네트워크 오류, 빈 응답을 내부 오류 코드로 매핑한다.
- [ ] 요청 timeout을 설정하고 허용 가능한 범위에서 제한적인 재시도 정책을 적용한다.
- [ ] 외부 API 오류의 상세 정보와 비밀 값이 Android 응답에 노출되지 않도록 정제한다.
- [ ] NVIDIA 클라이언트를 mock 처리해 성공, timeout, 인증 실패, 빈 응답 테스트를 추가한다.

## 완료 조건

- [ ] 유효한 이미지와 프롬프트로 한국어 레시피 텍스트를 생성한다.
- [ ] NVIDIA 오류가 서버 프로세스를 종료시키지 않고 규격화된 오류 응답으로 변환된다.
- [ ] API Key가 앱 번들, Git 추적 파일, 일반 로그 및 오류 응답에 노출되지 않는다.

## 개발 메모

- NVIDIA의 실제 모델 제공 여부와 멀티모달 요청 규격은 구현 시점의 API Catalog를 기준으로 확인한다.
- 레시피 결과는 참고용이며 식재료 식별, 알레르기, 식품 안전을 확정적으로 안내하지 않는다.
- 재시도는 timeout이나 일시적 5xx 등 안전한 조건에만 제한하고 동일 요청의 과도한 중복 과금을 방지한다.
